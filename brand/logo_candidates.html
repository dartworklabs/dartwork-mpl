🛡️ Shield 엠블럼 후보군 (1차 조율 완료)

세 개의 평행사변형 레이어가 정밀하게 중첩되어 구조적 깊이감을 주는 Shield 심볼과 결합된 최종 시안 3선입니다.

Option 1. classic

Shield + classic

정렬된 sans-serif 폰트에 두께 대조를 부여한 'classic' 타이포를 배치하여 정갈하고 세련된 완성형 대칭을 만듭니다. 가장 추천되는 표준 구성입니다.

Option 2. point

Shield + point

도트(.)를 틸 마커로 강조하여 `dartwork.mpl` 파일 시스템처럼 한눈에 들어오는 결합입니다. 정밀 차트 마커 포인트의 감성을 더해줍니다.

Option 3. mono

Shield + mono

코딩 환경 감성의 'monospace' 타이포를 결합한 극단의 개발자 친화적 디자인입니다. AI 에이전트 연동의 지적 정체성을 드러냅니다.
