# Gallery Examples

Sphinx-Gallery source for the dartwork-mpl docs site. Each `plot_*.py`
runs end-to-end and is rendered into a thumbnail page during the
docs build.

## Writing a new example

Follow the bundled recipes (`dm.get_prompt("03-recipes")`, source at
`src/dartwork_mpl/asset/prompt/03-recipes.md`); the lint catalog
(`src/dartwork_mpl/asset/prompt/02-anti-patterns.yaml`) blocks the
critical legacy patterns.
