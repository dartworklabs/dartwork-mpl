## Verified guidance policy

An ordinary local label enlargement permits the necessary content fitting
through the figure's existing method/settings. Start from retained layout
kwargs and adjust only needed margins/spacing. Keep physical canvas,
panel/container allocations and explicit ratios, data, colors, other typography
and legend's intended location. Do not refit already-fitting content, reapply a
preset, reset layout defaults or introduce a different engine.

Explicit user instructions take precedence. In particular, an explicit Axes
position lock prevents automatic geometry changes. Retain the lock and disclose
any clipping/conflict. Ask one relevant question only if protected constraints
must change or the safe existing fit is unclear; retain the original.

Inspect actual PNG/PDF and bounds after draw and export, accounting for active
native engines. Report necessary Axes movement rather than claiming geometry
invariance. Preserved panel allocation does not imply an unchanged data rectangle.
There is no universal pixel/mm tolerance. Retained source/revision lineage,
current-relative size changes and known in-place Line2D legend edits remain.
