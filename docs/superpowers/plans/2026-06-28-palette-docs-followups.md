## Task 1: Deterministic regeneration of docs example SVGs

**Why:** The committed example SVGs under `docs/api/images/` and `docs/usage_guide/images/` were generated before the new default cycle (`trustworthy`) and per-preset cycles landed. They still show old colors, and running the generators standalone rewrites every element ID (non-deterministic) so a plain regen is unreviewable. Make the generators self-deterministic, then regenerate once so the committed assets reflect the shipped color system.

**Files:**
- Modify: `docs/api/generate_assets.py` (add determinism shim to its `if __name__ == "__main__"` / `build_api_assets` entry)
- Modify: `docs/usage_guide/generate_assets.py` (same)
- Create: `docs/_static/scripts/_svg_determinism.py` (shared shim)
- Regenerate (commit the diffs): `docs/api/images/*.svg`, `docs/usage_guide/images/*.svg`
- Note: `docs/color_system/images/**` and `docs/fonts/images/**` are **gitignored** (build-time) — don't commit those.

**Interfaces:**
- Produces: `apply_svg_determinism()` in `_svg_determinism.py` — sets `os.environ["SOURCE_DATE_EPOCH"]` and `matplotlib.rcParams/rcParamsDefault["svg.hashsalt"]`. Idempotent, import-safe, no return value.

- [ ] **Step 1: Write the shared determinism shim**

Create `docs/_static/scripts/_svg_determinism.py`:

```python
"""Pin matplotlib's SVG output so docs assets regenerate byte-identically.

Mirrors docs/conf.py: SOURCE_DATE_EPOCH fixes the <dc:date>, svg.hashsalt
fixes element ids. Setting hashsalt on rcParamsDefault too means it
survives dm.style.use(...) resets. Call BEFORE importing dartwork_mpl /
pyplot in any standalone asset generator.
"""
from __future__ import annotations

import os

import matplotlib

SOURCE_DATE_EPOCH = "1735689600"  # 2025-01-01 UTC — matches docs/conf.py
HASHSALT = "dartwork-mpl-docs"


def apply_svg_determinism() -> None:
    os.environ.setdefault("SOURCE_DATE_EPOCH", SOURCE_DATE_EPOCH)
    matplotlib.rcParams["svg.hashsalt"] = HASHSALT
    matplotlib.rcParamsDefault["svg.hashsalt"] = HASHSALT
```

```python
from _svg_determinism import apply_svg_determinism  # noqa: E402

apply_svg_determinism()
```

(If the file already imports `sys`/`Path`, reuse them — don't duplicate imports; `ruff` will flag duplicates.)

**Migration mapping (legacy palette → curated target; preserve the numeric index 0–5):**

| Legacy | → Curated | Rationale |
|---|---|---|
| `ocean` | `corporate` | cool, professional, teal-anchored categorical |
| `nordic` | `muted` | soft, cool, low-chroma categorical |
| `vivid` | `spectrum` | full-wheel vivid — the direct successor |
| `pop` | `bold` | punchy high-contrast |
| `cyber` | `bold` | neon/energetic → high-contrast |
| `sunset` | `earth` | warm multi-hue categorical |
| `autumn` | `earth` | warm earthy — near-exact match |

Legacy palettes have 6 colors (indices 0–5); all targets have 8 (0–7), so index preservation is always valid. Exact hue is cosmetic for demo plots — the requirement is "distinct, non-clashing," which any curated categorical satisfies.
