## Task P0-1 — mathtext coherence (the DejaVu leak)

Every preset currently inherits `mathtext.fontset: dejavusans`, so math
segments (`$R^2$`, `$\mu m$`) render in DejaVu while labels are Roboto.

- In `base.mplstyle`: `mathtext.fontset: custom` with `mathtext.rm: Roboto`,
  `it: Roboto:italic`, `bf: Roboto:bold`, `sf: Roboto`,
  `tt: JetBrains Mono`, `cal: STIXGeneral:italic` (matplotlib-bundled),
  `mathtext.fallback: stixsans`, `mathtext.default: regular`
  (so bare mathtext matches body upright) — adjust names to what
  font_manager actually resolves; verify each resolves to a REAL file.
- Gate (in `tests/test_font_invariants.py`): render a label containing
  `$R^2 \mu m 10^3$` under `dm.style.use("scientific")` to SVG with
  `svg.fonttype: none` and assert **no `DejaVu`** in the output's
  font-family attributes; assert the body family appears. Repeat for the
  `-kr` stack (math stays Latin — assert no DejaVu, no tofu error).

## Task P0-3 — fallback-chain hygiene

Remove non-bundled system fonts (Lato, Open Sans, Arial, Helvetica,
Gothic A1, Freesentation, AppleGothic, Malgun Gothic) from
`font.sans-serif` in every mplstyle; the chain lists bundled families only
(+ terminal generic). Rationale's chain-anatomy notes that anything beyond
the bundle intentionally falls to matplotlib's default rather than a
machine-dependent font. Resolver goldens must be unchanged.
