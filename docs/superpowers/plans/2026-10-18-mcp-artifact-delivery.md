# MCP Artifact Delivery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver durable PNG/PDF/source/report/manifest bundles from one trusted plotting execution through two new MCP tools and five resource templates.

**Architecture:** A self-contained `mcp/artifacts/` capability owns pure parsing/lifetime policy, private disk publication and MCP transport. Its shell calls one declared MCP execution surface shared with the existing validator; the entry point only creates the server-bound store and registers handlers. Historical color comparison uses an explicit legacy discovery projection, independently of truthful full-live discovery and its exact extension gate.

**Tech Stack:** Python ≥3.10, Matplotlib/Agg, standard-library filesystem/JSON/UUID/hashing, FastMCP ≥2.13.3,<4, existing pytest/uv/Ruff/mypy; no new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-18-mcp-artifact-delivery-design.md` (Approved and implemented; final integration review pending); separate scoped approval: `docs/adr/0003-allow-scoped-mcp-artifact-discovery.md` (Accepted 2026-10-18).

## Global Constraints

- Source ≤512 KiB UTF-8; finite timeout in `(0, 120]` seconds; exactly five files, ≤32 MiB combined; immutable expiry seven days after publication; retrieval does not extend expiry.
- Members/order: `plot.png`, `plot.pdf`, `source.py`, `report.json`, `manifest.json`; MIME: `image/png`, `application/pdf`, `text/x-python`, `application/json`, `application/json`.
- Exact submitted source; full original logs/report; one execution and selected native Figure; no extra style/layout; export with `dm.save_formats(..., formats=("png", "pdf"), validate=False)`.
- Preserve existing defaults, statuses, hints, figure fallback, inherited cwd/save effects and incomplete validation. No new runtime/test dependencies; core remains importable without MCP.
- Add exactly `render_plot`, `get_plot_artifact` and five named templates; target counts 18/10/9/2. Frozen baseline bytes/digests, shipped colors/algorithms and all other exact surfaces stay unchanged.
- Same trusted OS-user scope; IDs are references, not authentication. No HTTP hosting, tenant scheme, hostile-code sandbox, global disk quota or scheduler.
- Document authored/changed definitions and tests with behavior/effects/failures. Tests mirror the capability under `tests/mcp/artifacts/` because `pyproject.toml` sets `testpaths=["tests"]`.

## Review Focus

1. A relative/empty/symlinked configured root must fail the new capability safely while old tools remain usable (Task 1/2).
2. A warning/incomplete checkpoint followed by export failure must retain acquired check IDs without publishing an ID (Task 2).
3. A killed publisher or reader racing expiry/publication must never expose partial bytes or delete another operation's work (Task 1).
4. Duplicate JSON keys, excessive nesting and altered expiry/hash/member data must fail closed without path disclosure (Task 1).
5. FastMCP 2 error transport must preserve JSON, structured metadata and `isError=true`, and all five MIME types must survive both versions (Task 2).

### Task 1: Typed policy and durable private bundle store

**Files:**
- Create: `src/dartwork_mpl/mcp/artifacts/{__init__,policy,store}.py` — declared surface, pure values/parsing/expiry, filesystem shell respectively.
- Create: `tests/mcp/artifacts/test_artifact_policy.py`, `test_artifact_store.py` — pure generated inputs and real temporary filesystem contracts.

**Interfaces:**
- Consumes: standard library only; configuration root supplied once by server wiring, injected timezone-aware UTC `now` for deterministic expiry.
- Produces through `artifacts.__all__`: `ArtifactId`, `ArtifactMember`, `RenderRequest`, `Manifest`, `StoredBundle`, `ArtifactBytes`, `ArtifactStore`, `StagedBundle`, named outcomes and functions below; transport registration exports arrive in Task 2.
- `parse_render_request(code: str, figure_var: str = "fig", timeout_seconds: float = 20.0, chart_type_hint: str | None = None) -> RenderRequest | InvalidRequest`; `parse_artifact_id(raw: str) -> ArtifactId | InvalidRequest`; `parse_manifest(raw: bytes) -> Manifest | CorruptArtifact`; `is_expired(manifest: Manifest, now: datetime) -> bool` in `policy.py`, importing no I/O/framework/other feature.
- Frozen values enforce invariants: lowercase full UUID4 hex, five-member enum, UTC RFC3339 `Z`, exactly v1 fields, sizes/hashes and publication-to-expiry interval. Bound manifest input to 512 KiB, depth 8 and 128 total object fields; reject duplicates/unknown fields/nonfinite numbers. These internal parser bounds do not change the combined bundle limit.
- `configure_store(configured_root: str | None) -> ArtifactStore | ConfigurationError` is the only store-handle constructor; `None` selects `~/.cache/dartwork-mpl/artifacts`, nonempty absolute configured roots only. Resolve once; lazily create owner-only directories; reject unsafe/symlinked roots. Only server wiring calls this constructor in production.
- `ArtifactStore.staging() -> AbstractContextManager[StagedBundle]`; the opaque stage exposes only a store-created `output_stem: Path` for trusted export. `ArtifactStore.publish(stage: StagedBundle, source: bytes, report: dict[str, Any], now: datetime) -> StoredBundle | StoreFailure`; `load(artifact_id: ArtifactId, now: datetime) -> StoredBundle | StoreFailure`; `read_member(artifact_id: ArtifactId, member: ArtifactMember, now: datetime) -> ArtifactBytes | StoreFailure`.
- `StoreFailure` is a union of frozen `NotFound`, `Expired`, `CorruptArtifact`, `ArtifactTooLarge`, `PublicationError`; configuration/request refusals are separate. Each carries only meaningful safe diagnostic fields; do not use exceptions for these expected outcomes. `StoredBundle` carries parsed manifest and verified five file contents; `ArtifactBytes` carries bytes and MIME. No root/path crosses the wire.
