# Colormap explorer — POC comparison (temporary)

> This page is a temporary side-by-side comparison of two redesigns for the
> colormap explorer widget. It will be removed once a direction is picked.

## Option A — Underline tabs (category picker)

One category visible at a time, switched by an underline tab. `Color / Mono`
appears as a quiet underline toggle inside each panel. Closest in spirit to
the current widget but with the pill / dot / fill removed.

```{raw} html
:file: _static/colormap_poc_a.html
```

---

## Option B — Vercel-style row list with sticky section nav

All categories visible in one scrollable column. A sticky top bar holds the
category jump-links + the `Color / Mono` toggle, so the toggle and the
section nav both stay visible while you scroll. No tabs to click through.

```{raw} html
:file: _static/colormap_poc_b.html
```

---

## Notes

- Both POCs render fake gradient stops — production wires real `dc.*` colormaps.
- `Color / Mono` toggle works in both. Hover and active states are subtle and
  text-driven (no fill chips).
- Pick one (or a hybrid) and the final version will replace
  `docs/color_system/images/colormap_explorer.html` (currently generated by
  `docs/color_system/generate_assets.py`).
