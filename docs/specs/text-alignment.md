# 이미 놓인 글자의 정렬 (#812)

> **한눈에**
>
> 포레스트 플롯의 연구명과 눈금은 그 자리에 둔다. 추정값과 두
> 신뢰구간 끝의 소수점만 같은 세로선에 놓는다.

## 요구

사용자가 `ax.text`, `annotate`, `bar_label` 또는 눈금으로 이미 그린
글자 중에서 맞출 대상을 고른다. 축, 머리글, 눈금과 행의 자리는
그대로 두고 가로만 움직인다. 막대 끝의 값은 각각 자기 막대에 붙인다.

## 공개 표면

`dm.align_texts(texts, how)`. `how`는 `"left"`, `"right"`, `"center"`,
`"decimal"`이다. 같은 Figure에서 보이는 한 줄짜리 글자를 받는다.
앞의 세 가지는 눈금을 포함한 기존 Text의 가로 정렬을 바꾼다.
반환값은 입력 순서대로 각 행을 그리는 Text의 목록이다.

소수점 정렬은 같은 Axes에 직접 놓은 글자에서 한다. 각 행에 같은
수의 숫자가 있어야 한다. 숫자가 없거나 개수가 다르면 원래 글자를
돌려준다. 수식, 화살표와 회전한 글자는 소수점 정렬 대상 밖이다.
소수점을 맞춘 행은 원래 글자를 숨기고, 원래 문자열을 거기에 남긴다.
화면에는 한 행을 그리는 Text가 들어가고, 숫자의 빼기 부호는 U+2212다.

## 메커니즘

변 정렬은 원래 변 위치의 중앙값을 택해 총 가로 이동을 줄인다.
각 글자의 y는 원래 변환을 계속 쓴다. 소수점 정렬은 원래 행의
왼쪽 변 위치의 중앙값을 기준으로 잡고, 원래 행의 기준선을 쓴다.

한 행에 숫자가 셋이면 탭 정지점도 셋이다. 정수부는 정지점에서
끝나고 소수부는 거기서 시작한다. 숫자에 괄호를 붙인다. 정지점
사이의 간격만 각 글꼴의 가장 긴 조각을 `textpath`로 재서 정한다.
힌팅 없는 폭을 포인트로 쓰므로 비례폭 숫자에도 맞는다. 문자열에
공백을 더하거나 글꼴의 숫자 기능을 켤 이유가 없다.

조각은 기준선을 나눠 쓰는 native Annotation이다. 행 Text는 조각의
합친 상자를 돌려준다. 레이아웃과 check는 그 상자를 한 번씩 읽는다.

## 판정과 힌트

`TEXT_MISALIGNMENT`는 비슷한 크기의 글자가 세 줄 이상 같은 Axes
변 바깥의 가까운 x를 향할 때만 본다. 각 숫자 앞까지 화면에 찍힌
폭을 렌더러로 재고, 소수점 위치가 어긋나거나 이미 비슷한 변이
조금씩 어긋나면 알린다. 눈금, 범례, 화살표, plot 안의 값과 주석은
이 단서가 아니다. 한 숫자를 오른쪽 변에 맞춘 열도 그대로 읽힌다.

철학 3절의 판정: 새 글자를 같은 x에 두고 변을 맞추는 데는 `ha`로
충분하다. 이미 그린 글자들의 위치와 변환이 다르면 공통 변은
재야 한다. 한 행에 소수점이 여러 개면 여러 정지점도 필요하다.
기존 check는 이 어긋남을 알려주지 않았다. 그래서 정렬은 기능에,
명백한 어긋남은 check와 그 힌트에, 언제 쓸지는 skill에 둔다.

## 검증

| 검사 | 기준 |
| --- | --- |
| 비례폭 숫자 글꼴 두 종 이상, Agg 100/200/300 dpi와 PDF·SVG | 정지점마다 퍼짐 ≤ 0.01 pt |
| PDF·SVG에서 조각 상자와 한 Text 상자 | 차이 ≤ 0.1 pt |
| 레이아웃과 resize 후 재레이아웃 | 잘린 글자 0, 눈금 그대로, 행마다 Text 하나 |
| 포레스트와 한국어 장면 | 새 픽셀 기준 두 장 |
| 코퍼스와 복사한 평가 sweep | 새 발견의 그림과 이유를 확인 |
